高频十五五规划纲要

2026年3月12日，十四届全国人大四次会议表决通过《中华人民共和国国民经济和社会发展第十五个五年规划和2035年远景目标纲要》。下列关于该纲要主要目标指标的说法，正确的是（　　）。

  1. A纲要设置了20项主要指标，其中民生福祉类指标数量最多，共7项
  2. B纲要提出全社会研发经费投入年均增长5%以上，与"十四五"目标保持一致
  3. C纲要提出单位国内生产总值二氧化碳排放累计降低3.8%左右
  4. D纲要提出粮食综合生产能力达到1.4万亿斤左右

正确答案 A

A 正确。20项主要指标的分布是：经济发展3项、创新驱动3项、民生福祉7项、绿色低碳5项、安全保障2项。民生福祉类最多。

B 错。研发经费投入的目标是年均增长7%以上。

C 错。"十五五"五年累计目标是单位GDP二氧化碳排放累计降低17%；3.8%左右是2026年当年的年度目标。这两个数字最容易互换出题。

D 错。粮食综合生产能力目标是1.45万亿斤左右；1.4万亿斤左右是2026年的粮食产量年度目标。同样是两个数字的互换。

命题依据：2026年3月12日十四届全国人大四次会议表决通过，3月13日全文播发；纲共18篇，含6方面109项重大工程。其他可记数字：数字经济核心产业增加值占GDP比重12.5%；劳动年龄人口平均受教育年限11.7年；人均预期寿命80岁；能源综合生产能力58亿吨标准煤。

高频政府工作报告

2026年3月5日，国务院总理李强在十四届全国人大四次会议上作《政府工作报告》。下列关于2026年发展主要预期目标的说法，正确的是（　　）。

  1. A国内生产总值增长5%左右
  2. B城镇新增就业1200万人以上，城镇调查失业率5.5%左右
  3. C居民消费价格涨幅3%左右
  4. D赤字率拟按3%左右安排

正确答案 B

A 错。2026年GDP增长目标为4.5%—5%，不是"5%左右"（这是2025年的提法）。这是本次最值得记住的一个变化。

B 正确。城镇新增就业1200万人以上，城镇调查失业率5.5%左右，与上年持平。

C 错。居民消费价格涨幅2%左右。

D 错。赤字率拟按4%左右安排，赤字规模5.89万亿元、比上年增加2300亿元。

命题依据：2026年3月5日李强作报告，3月12日十四届全国人大四次会议表决通过。财政口径：一般公共预算支出规模首次达到30万亿元、比上年增加约1.27万亿元；拟发行超长期特别国债1.3万亿元；另发行特别国债3000亿元；拟安排地方政府专项债券4.4万亿元。其他目标：粮食产量1.4万亿斤左右；单位GDP二氧化碳排放降低3.8%左右；居民收入增长和经济增长同步。

高频7·30政治局会议

2026年7月30日，中共中央政治局召开会议，分析研究当前经济形势，部署下半年经济工作。下列关于此次会议及2026年上半年经济形势的说法，正确的是（　　）。

  1. A会议认为今年以来我国经济呈现"动能向新、结构向优"的发展态势
  2. B上半年我国国内生产总值同比增长5.4%，为近5年同期最大增量
  3. C会议要求实施从紧的货币政策和收缩性财政政策，加大逆周期调节力度
  4. D会议提出继续综合整治"内卷式"竞争，但对"人工智能+"行动未作部署

正确答案 A

A 正确。"动能向新、结构向优"是这次会议对当前经济态势的定调，会议同时要求"推动经济持续向新向优向好发展"，努力实现"十五五"良好开局。

B 错。上半年GDP总量69.6万亿元，同比增长4.7%；GDP增量3.6万亿元为近5年同期最大。5.4%是规模以上工业增加值的同比增速，两个数字被调换了。

C 错。会议要求实施更加积极的财政政策和适度宽松的货币政策，加大逆周期调节力度。

D 错。会议明确"深入实施'人工智能+'行动，发展智能经济新形态"，同时继续综合整治"内卷式"竞争、常态化解决企业账款拖欠问题。

命题依据：2026年7月30日中共中央政治局会议，新华社、央视新闻报道。同期其他上半年数据：制造业增加值占GDP比重升至26.2%；新能源汽车零售渗透率连续三个月超过60%；夏粮总产量3014.9亿斤、首次突破3000亿斤。会议还提出扎实推进水网、新型电网、算力网等"六张网"规划建设。
"六张网"的完整六项表述，我检索到的公开报道只确认了水网、新型电网、算力网三项，考前请以新华社会议通稿原文为准，不要按我这里的部分列举去记全部六项。

常规建党105周年

2026年是中国共产党成立105周年，也是红军长征胜利90周年。关于2026年开展的相关纪念活动，下列说法正确的是（　　）。

  1. A"强国复兴有我"群众性主题宣传教育活动由中央宣传部等21家部门联合部署，紧紧围绕庆祝建党105周年、纪念红军长征胜利90周年开展
  2. B相关部门部署的活动以"重走长征路"为主要形式，但明确不组织重温入党誓词活动
  3. C退役军人事务部等部门部署开展的是"追寻·2025·清明祭英烈"活动
  4. D2026年9月30日烈士纪念日向人民英雄敬献花篮仪式在人民大会堂举行

正确答案 A

A 正确。2026年5月，中央宣传部、中央统战部、中央社会工作部、国家发展改革委、教育部等21家部门联合印发通知，围绕庆祝建党105周年、纪念红军长征胜利90周年部署"强国复兴有我"群众性主题宣传教育活动。

B 错。通知明确组织干部群众参加重走长征路、敬献花篮、祭扫烈士墓、重温入党入团入职誓词等活动。

C 错。是"追寻·2026·清明祭英烈"，由退役军人事务部、中央网信办、共青团中央、全国少工委四部门于2026年3月联合部署。

D 错。仪式在天安门广场举行，习近平等党和国家领导人出席。

命题依据：2026年3月四部门"追寻·2026·清明祭英烈"通知；2026年5月中央宣传部等21部门"强国复兴有我"通知；2026年9月30日烈士纪念日仪式。长征胜利90周年对应的是1936年10月红军三大主力会师。

高频陕西

2026年2月24日，陕西省委、省政府召开全省深化开展"三个年"活动全面提升"三服务"质效动员部署会。下列关于陕西"三个年"活动及"三服务"的说法，正确的是（　　）。

  1. A"三个年"活动指高质量项目推进年、营商环境突破年、干部作风能力提升年
  2. B"三服务"指服务发展、服务民生、服务大局

  4. D"八场硬仗"是2026年首次提出的概念

高频陕西

习近平总书记来陕考察、听取陕西省委和省政府工作汇报时，对陕西提出"四个着力"的重要要求。下列不属于"四个着力"的是（　　）。

  1. A着力强化科技创新、建设现代化产业体系
  2. B着力推动城乡融合发展、促进共同富裕
  3. C着力推动发展方式绿色低碳转型、提升生态文明建设水平
  4. D着力推进社会治理现代化、建设更高水平平安陕西

正确答案 D

第四项"着力"是着力扩大对内对外开放、打造内陆改革开放高地，与D项表述不符。

完整四项：着力强化科技创新、建设现代化产业体系；着力推动城乡融合发展、促进共同富裕；着力推动发展方式绿色低碳转型、提升生态文明建设水平；着力扩大对内对外开放、打造内陆改革开放高地。

  2. B深入实施"单极带动、多点支撑、两区协同"战略

高频生态环境法典

2026年3月12日，十四届全国人大四次会议表决通过《中华人民共和国生态环境法典》，自2026年8月15日起施行。下列关于该法典的说法，正确的是（　　）。

  1. A这是我国继《民法典》之后第二部以"法典"命名的法律
  2. B该法典的调整范围仅限于污染防治，不涉及生态保护与绿色低碳发展
  3. C这是我国第一部以"法典"命名的法律
  4. D该法典由国务院制定并公布

正确答案 A

A 正确。继2020年《民法典》之后，生态环境法典是我国第二部以"法典"命名的法律。

C 错。我国第一部法典是《民法典》。

D 错。由全国人民代表大会表决通过，不是国务院。

B项表述过于绝对。法典的编纂方式是把分散的生态环境法律规范系统整合，覆盖污染防治、生态保护、绿色低碳发展等领域。

命题依据：2026年3月12日十四届全国人大四次会议表决通过，2026年8月15日起施行。陕西层面已有落地动作：陕西日报、西部法制报2026年5月、8月多次报道"让生态环境法典浸润三秦大地""法典赋能 山青水长"，并称该法典精准适配黄河流域水土流失治理、秦岭生态修复、关中产业转型；延安宜川县设立"黄河流域生态警务联勤站"，司法机关以预防性公益诉讼、替代性修复、劳务代偿等方式强化保护。
法典的"第二部法典"定位、通过日期与施行日期，我检索到的多个来源一致；但法典的编、章结构与条文数，请考前以全国人大公布的法律文本为准。

新法施行治安管理处罚法

新修订的《中华人民共和国治安管理处罚法》自2026年1月1日起施行。下列行为中，属于此次修订新增纳入治安管理处罚范围的是（　　）。

  1. A盗窃他人财物
  2. B高空抛物
  3. C殴打他人造成轻微伤
  4. D故意损毁公私财物

正确答案 B

B 正确。高空抛物是此次修订新增纳入的行为之一。

A、C、D三项在修订前的治安管理处罚法中已有规定，不属于新增。

此次修订新增纳入管理范围的行为还包括：考试作弊、组织领导传销、损害英雄烈士保护、以抢控驾驶操纵装置等方式干扰公共交通工具正常行驶、升放（燃放）携带明火的升空物体、无人机"黑飞"、未对动物采取安全措施致使动物伤害他人等；同时优化完善了治安案件办理程序。

命题依据：新修订的治安管理处罚法，2026年1月1日起施行，新华社及多家媒体"2026年1月1日起施行新规"清单均有列入。

常规民法典·相邻关系

老李与老王家相邻，老李在自家院内种了一棵香椿树，树根延伸至老王家房屋地基下方，导致老王家地面开裂。老王要求老李排除妨害，老李以"树在自己院里"为由拒绝。关于本案，下列说法正确的是（　　）。

  1. A老王只能请求损害赔偿，无权请求排除妨害
  2. B老李有权在自己院内自由种树，老王无权干涉
  3. C老王可以请求老李排除妨害，因相邻关系应按照有利生产、方便生活、团结互助、公平合理的原则处理
  4. D该纠纷只能通过诉讼解决，不能协商或调解

正确答案 C

C 正确。《民法典》第288条规定，不动产的相邻权利人应当按照有利生产、方便生活、团结互助、公平合理的原则，正确处理相邻关系。

A 错。《民法典》第236条规定，妨害物权或者可能妨害物权的，权利人可以请求排除妨害或者消除危险。排除妨害与损害赔偿可以并行主张，并非只能选其一。

B 错。行使自己的物权不得损害他人的合法权益，"树在自己院里"不构成免责理由。

D 错。相邻关系纠纷可以先协商，也可以申请人民调解，诉讼不是唯一途径。

命题依据：延续2026年3月卷常识判断第14题（果树树枝越界案）的考法。该卷第14、15、19题分别考相邻关系、交通肇事逃逸、《民法典》居住权，三题都是"给案例问法条"，本次按同一路子出题。

常规价值规律

下列关于价值规律的说法，正确的是（　　）。

  1. A商品的价值量由生产该商品的社会必要劳动时间决定
  2. B价格围绕价值上下波动是对价值规律的否定
  3. C价值规律要求商品交换以使用价值量为基础实行等价交换
  4. D供求关系的变化决定商品的价值

高频价格歧视

某景区对本地居民实行门票半价，对外地游客收取全价。这一"同景不同价"的定价策略，其经济学依据主要是（　　）。

  1. A本地居民的收入水平普遍高于外地游客
  2. B外地游客对门票的需求价格弹性比本地居民小
  3. C景区运营的边际成本对外地游客更高
  4. D本地居民对门票的需求价格弹性比外地游客小

正确答案 B

B 正确。这种差别定价（价格歧视）成立的前提，是不同消费者群体的需求价格弹性不同。外地游客来一趟不易、替代选择少，需求更刚性、弹性更小，因此可以收全价；本地居民可多次游玩、替代选择多，弹性大，降价能带来更多客流。

A 错。差别定价的依据是需求弹性，与收入水平高低没有必然关系。

C 错。多接待一位游客的边际成本，不会因游客来自哪里而不同。

D 错。把两个群体的弹性说反了。

命题依据：直接对标2026年3月卷第10题（航空公司"同座不同价"，考需求价格弹性）。该题型的唯一考点就是"弹性小的收高价、弹性大的收低价"，换个场景就会再考一次。

  2. B冬天用湿手摸户外的铁栏杆会被"粘住"，是因为手上的水发生了凝固
  3. C夏天从冰箱取出的饮料瓶外壁"出汗"，是瓶内水分渗出到瓶壁的结果
  4. D汽车后视镜成像利用的是光的折射原理

D 错。后视镜利用的是光的反射。
